## 1 设计目标与原则

本设计重新规划 `hdai_base` 系统托盘 AI 助手的对话窗口，在保留 linkinai
既有能力（Markdown/代码块渲染、上下文工具、回复动作、会话选项）的基础上，
将单栏对话升级为「可缩进侧边栏 + 三段式主区」布局，提升信息组织与可操作
性。

设计原则：

1. **信息分层**：会话/知识等次级信息进入侧边栏网格，主区专注对话；
2. **状态可见**：模型状态、上下文消耗、任务状态在标题栏与状态栏显式呈现；
3. **就地编辑**：消息编辑、会话改名、命令输入均就地完成，减少弹窗跳转；
4. **权限感知**：上下文工具按「普通用户建议 / 管理员执行」分级呈现；
5. **可读性优先**：深浅色背景、正常/编辑态控件均高对比（AGENTS.md UI
   要求），编辑态一律白底深字。

## 2 整体布局

对话窗口（Dialog，`size="xl"`）分为三列两行，纵向结构如下：

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 标题栏：窗口名称 · 模型状态徽标（未配置/正常/异常）                        │
├───────────────┬────────────────────────────────────────────────────────────┤
│ 侧边栏        │ 主对话区                                                    │
│ （可缩进）     │ ┌────────────────────────────────────────────────────────┐ │
│ ┌───────────┐ │ │ ① 上下文敏感区                                        │ │
│ │ 会话历史   │ │ │   [记录信息]              [☑插入上下文] [在讨论区打开] │ │
│ │ 网格（折叠）│ │ ├───────────────────────────────────────────────────────┤ │
│ └───────────┘ │ │ ② 对话历史 + 输入栏                                    │ │
│ ┌───────────┐ │ │   · 消息列表（用户/助手，带工具栏）                     │ │
│ │ 知识库选择 │ │ │   · 输入栏（/命令、历史浏览、发送、用户设置）          │ │
│ │ 网格（折叠）│ │ └───────────────────────────────────────────────────────┤ │
│ └───────────┘ │ │ ③ 状态栏                                               │ │
│               │ │   [模型状态] [输入/输出上下文] [任务状态] [联网/思考…]   │ │
├───────────────┴────────────────────────────────────────────────────────────┤
```

窗口高度 70vh（最小 560px）；宽度使用 Dialog `xl`（约 1140px）。侧边栏
默认 260px，宽度可拖拽调节（180–800px）并持久化；右缘垂直把手点击收起，
收起后仅保留一条 22px 的展开把手。

## 3 分区域设计

### 3.1 标题栏（窗口顶部）

- 左侧：窗口图标 + 窗口名称（「AI 助手」）+ **模型状态徽标**；
- 模型状态徽标为带色圆点 + 文案，取值：

| 状态 | 文案 | 颜色 | 触发条件 |
| --- | --- | --- | --- |
| 未配置 | 模型未配置 | 灰 | 无默认模型 |
| 正常 | 模型正常 | 绿 | 默认模型就绪、提供方可用 |
| 配置异常 | 模型配置异常 | 红 | 提供方停用/URL 缺失/缺少 API Key |
- 右侧：会话操作按钮（新建会话、删除当前会话），沿用现有图标按钮；
- 点击模型状态徽标可打开「模型配置」设置页（管理员）或显示状态详情
  （普通用户）。

### 3.2 侧边栏（左侧，可缩进）

- 纵向排列若干**信息网格**；网格由**标题栏**（折叠图标 + 网格名称 +
  可选操作按钮）与内容区组成；
- 点击折叠图标或标题栏可收缩/展开网格；收缩后仅剩标题栏；侧边栏整体
  可收缩/展开：展开时侧边栏右缘有垂直把手，点击收起；收起后仅剩垂直
  把手，点击展开；网格的收缩/展开状态、高度与侧边栏整体状态随用户
  设置持久化（`hdai.user.settings`）；侧边栏宽度通过右缘拖拽手柄调节
  （180–800px）并同样持久化；
- 初始提供两个网格：

**网格 1：会话历史**

- 内容：当前用户会话列表（名称 + 消息数/更新时间），点击切换会话；
- 会话行提示框（title）显示统计信息：消息数、输入/输出 tokens 与
  更新时间（绝对时间）；有新消息的会话按更新时间自动置顶
  （`write_date desc`，消息写入时刷新会话时间戳）；
- 操作：会话行悬停显示「改名」「删除」图标；顶部「+」新建会话；
- 改名就地编辑（输入框 + 回车确认 / Esc 取消）；删除需二次确认
  （确认框，避免误删）；
- 支持会话搜索（网格顶部搜索框，过滤名称）。

**网格 2：知识库选择**

- 内容：知识库检索范围选择（已实现）——「使用知识库」开关 + 当前用户
  可见的 `hdai.knowledge.document` 多选列表；选择随会话保存，发送消息时
  按所选文档范围检索（`action_search(document_ids=...)`）并把结果注入
  系统上下文；`hdai_knowledge` 未安装时显示「暂无可用知识文档」。

### 3.3 主对话区

#### ① 上下文敏感区（顶部）

- 左对齐显示**记录信息**，右对齐显示**插入控制**与**在讨论区打开**按钮：

| 场景 | 记录信息内容 |
| --- | --- |
| 列表/卡片视图 | `共 nn 条 xx模型记录`（视图记录总数，非选中数；如「共 3 条销售订单记录」） |
| 表单视图 | 记录名称（display_name） |
| 其他视图（pivot/graph/calendar 等） | `当前 x 视图不支持上下文感知`（x 为视图名称） |
| 无上下文/空记录 | 空列表显示 `共 0 条 xx模型记录`；记录缺失显示 `未检测到当前记录`（灰字） |

- 插入控制：复选框 + 文案「插入上下文」；选中后将当前上下文快照注入
  对话 system 消息（沿用现有 attach_context 机制），取消则不注入；
  当前无可用记录（空列表/缺失记录/不支持视图）时控件禁用；
- 在讨论区打开按钮：**预留**。当前点击提示「功能未实现，将在后续版本
  提供」，实际集成后续再挂接（`action_open_in_discuss` 为独立 stub，
  不依赖 linkinai 系列模块）；
- 记录信息与按钮之间右对齐排列（无分隔线）；主题跟随 Odoo 全局。

#### ② 对话历史 + 输入栏（中部，flex 占满）

**消息列表**：

- 用户消息与助手消息均有**工具栏**（常显）；
- 用户消息右对齐、气泡使用品牌色背景（白字）；助手消息左对齐、浅色
  背景（深色主题下保持高对比）；
- 用户消息工具栏：`复制`、`编辑`、`重新生成`；
  - 复制：复制消息文本到剪贴板；
  - 编辑：就地切换为文本域（白底深字），回车提交；提交后清空该消息
    之后的所有助手消息，并重新发起请求；
  - 重新生成：清空该用户消息对应的助手回答，重新调用模型，新回答
    替换旧回答（期间显示生成中状态）；
- 助手消息按 linkinai 设计：
  - Markdown/代码块/mermaid/svg 格式化渲染（复制/下载）；
  - 消息工具栏：`复制`、`发送为消息`、`记入日志`（Send as Message /
    Log as Note）；
  - **上下文工具卡片**：工具调用以卡片呈现（名称、参数、状态）；工具
    条件允许时直接执行；否则自动判断：
      - 需要安装模块 → 普通用户显示「建议安装 xxx」，管理员显示
        「安装」按钮（`action_install_module`）；
      - 需要白名单 → 普通用户显示「建议加入白名单」，管理员显示
        「加入白名单」按钮（`action_whitelist_add`）；
- 生成中：助手气泡显示光标动画与「正在生成…」，气泡工具栏出现「停止」
  按钮，可中断生成（前端中止流式请求并丢弃未完成的回答）。

**输入栏**：

- 多行文本域（回车发送，Shift+Enter 换行）；
- **历史会话浏览**：输入区为空时按 `↑` 进入消息浏览状态——`↑`/`↓`
  滚动浏览历史用户消息（不修改输入区）；在当前消息上改变光标或输入
  字符即进入修改状态（输入区显示该消息内容并允许编辑）；
- 输入区支持 `/` 命令：输入 `/` 弹出命令智能提示列表（过滤匹配），
  支持 Tab 补全；初始命令：

| 命令 | 功能 |
| --- | --- |
| `/help` | 显示命令帮助 |
| `/settings` | 打开用户设置对话框（语言/推理/联网/默认 Prompt） |
| `/compact` | 压缩当前会话上下文（保留摘要，占位，待后续实现） |
| `/export` | 导出会话（JSON/Markdown 下载） |
| `/share` | 生成会话共享链接（占位，待后续实现） |

- 输入栏右侧按钮：**发送**（主按钮，回车等效）、**用户设置**（齿轮图标，
  打开用户设置对话框）。

#### ③ 状态栏（底部）

- 从左到右：
  1. **任务状态**：空闲 / 正在生成 / 正在执行工具 / 出错（红）；
  2. **输入/输出上下文消耗**：`输入 1.2k · 输出 3.4k · 上下文 12%`
    （数据来自会话 usage 统计）；
  3. **能力控件**（按模型能力 × 管理员开放权限显示）：思考强度（下拉框，
    关/低/中/高）、联网搜索（地球图标开关）、流式（闪电图标开关）、
    默认 Prompt（下拉框，保留一定宽度显示内容）与管理；控件单行排列，
    悬停显示当前状态/禁用原因（禁用控件由外层 span 承载提示，避免
    disabled 元素不触发原生 title），避免文字换行；
- 模型状态不显示模型名（状态徽标在标题栏）；能力控件在无模型或能力
  未开放时禁用，悬停显示原因提示。
- 状态栏与对话框整体不出现滚动条：对话框高度随视口约束（`100vh - 2rem`），
  仅消息区内部纵向滚动。

## 4 交互细则

### 4.1 消息编辑与重新生成的状态流

```
用户点「编辑」→ 就地文本域 → 回车提交
    → 删除该用户消息之后的全部消息（含旧助手回答）
    → 发送新请求 → 流式新回答追加（替换占位）
用户点「重新生成」→ 仅删除对应助手回答 → 重新请求 → 新回答替换
```

编辑/重新生成期间输入栏禁用，防止并发提交。

### 4.2 命令状态

- 命令提示：输入 `/` 弹出列表，输入字符过滤；Tab 补全；Enter 执行
  匹配命令（若存在匹配历史消息则不拦截）；
- 命令执行结果以系统消息样式插入对话或打开对应对话框；
- 未知命令提示 `/help` 查看帮助。

### 4.3 键盘快捷键

| 按键 | 功能 |
| --- | --- |
| `↑`（输入区空） | 进入历史消息浏览 |
| `↑`/`↓`（浏览态） | 滚动历史用户消息 |
| `Enter` | 发送（非 Shift） |
| `Shift+Enter` | 换行 |
| `Esc` | 取消编辑/关闭提示 |
| `Ctrl+K` | 聚焦输入栏（预留） |

### 4.4 侧边栏状态持久化

- 网格折叠状态、网格高度、侧边栏收起状态与侧边栏宽度存入用户设置
  （`hdai.user.settings` 扩展字段），下次打开保持。

## 5 样式与可访问性

- 编辑态控件（会话改名输入、消息编辑文本域、命令输入）一律
  `background: #fff; color: #1f2937; border: 1px solid #d1d5db`，
  `:focus` 同规格 + 蓝描边；
- 彩色背景上的控件单独配色：用户气泡操作按钮浅色
  （`#e0e7ff` 系）、深色区域文字白/浅色；
- 主题跟随 Odoo 全局：主表面/文字/边框/强调色使用 Odoo SCSS 变量
  （`$o-view-background-color`、`$o-brand-lightsecondary`、
  `$o-main-text-color`、`$o-brand-primary` 等），不单独实现主题切换；
- 图标按钮带 `title`（对话框关闭按钮另有 `aria-label`）；键盘可操作。

## 6 状态与数据来源

| 显示 | 数据来源 |
| --- | --- |
| 模型状态 | `hdai.session._get_model_status()`（扩展示例文案） |
| 上下文消耗 | 会话 `input_tokens/output_tokens/context_tokens` |
| 记录信息 | 表单视图：`router.current`/`currentController`；列表/卡片视图：
  视图控制器发布的记录集（`hdai_view_context` store：整份 id 列表 +
  视图总数，非选中集；后端 `action_get_list_context` 计数/落快照） |
| 会话历史 | `hdai.session.search_read(user_id)`（名称/消息数/更新时间） |
| 任务状态 | 前端流式状态机（idle/streaming/tool/error） |
| 能力控件 | `hdai.model._allowed_options()` |

## 8 实施顺序建议

5. 状态栏与能力控件；
6. 浏览器深浅色/编辑态实测与 i18n 词条补齐。
